# SolidCraft Bearings

Bearing models for use in SolidCraft designs. All dimensions are in millimetres.

Open `.sc` files in SolidCraft. A STEP export is also included for `MF85ZZ`.

## Files

- `rubber-seal/`: 21 MR-series rubber-sealed (`2RS`) models.
- `MR106-2RS - 10mmx6mm.sc`: original template for the rubber-sealed models.
- Other root-level models: `6704ZZ`, `F6904ZZ`, `MF85ZZ`, and `MR63ZZ`.

Rubber-sealed filenames follow:

```text
<part number>-2RS - <outer diameter>x<inner diameter>x<width>.sc
```

For example, `MR106-2RS - 10x6x3.sc` has a 10 mm outer diameter,
6 mm bore, and 3 mm width.

## Parameters

Each rubber-sealed model was generated by reopening the template and changing
`InnerDiameter`, `OuterDiameter`, and `Width` to the sizes above.

The template's other user parameters are retained:

- `RaceWidth = 0.5 mm`
- `RaceGasket = Width - 0.25 mm`

The generated models were checked for bounding dimensions, volume, and saved
parameter values. They are simplified bearing representations, not detailed
internal bearing assemblies; confirm manufacturer dimensions for your application.

### Pending: MR31

MR31 (1 mm ID, 3 mm OD, 1.5 mm width) is not included. At that size, the
template's 0.5 mm race width makes sketch circles coincide and the rebuilt
model loses its bore. A smaller race width needs to be agreed before generation.

## Local files

machine-specific `opencode.json` configuration are excluded from Git.
